# ADR-0017: 四因子置信度模型

## Status
Implemented

## Context
形态检测器需要评估检测到的形态信号的可靠性。置信度（confidence）直接影响加权投票的综合评分，进而决定是否触发交易。

### 替代方案

1. **单因子模型**：仅基于形态完成度计算置信度
2. **四因子加权模型**：从多个维度综合评估信号质量
3. **动态权重模型**：根据市场状态动态调整因子权重

## Decision

采用方案 2：四因子加权模型。

因子定义：
| 因子 | 权重 | 含义 |
|------|------|------|
| completion（完成度） | 0.4 | 形态结构是否完整、规范 |
| volume（成交量） | 0.3 | 关键位置是否有放量确认 |
| trend（趋势共振） | 0.2 | 信号方向是否与更大级别趋势一致 |
| momentum（动量） | 0.1 | 价格动量是否支持信号方向 |

理由：
- 单因子模型过于粗糙，容易产生高完成度但低质量的假信号（如缩量突破）
- 动态权重模型复杂度高，当前数据量不足以支撑权重学习
- 四因子模型在可解释性和区分度之间取得平衡：完成度权重最高（形态结构是核心），动量权重最低（辅助确认）

权重通过 `cai_sen_v2.yaml` 的 `confidence_factors.weights` 配置，支持后续调优。

## Consequences

### Positive
- 多维度评估减少低质量信号
- 权重可配置，便于策略优化
- 模型可解释，每个因子对应明确的交易直觉

### Negative
- 因子权重需要经验或回测确定，初始值可能不是最优
- 部分因子（如趋势共振）计算依赖更大时间窗口的数据
