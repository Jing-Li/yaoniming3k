# ADR-0019: 自适应参数优化引擎

## Status
Superseded by ADR-0020（网格智能蔡森参数法）

> **注意**：此 ADR 原计划引入 Optuna TPE + Walk-Forward，但项目后续决定采用 LLM 驱动的智能参数优化方案（网格智能蔡森参数法），利用大模型理解蔡森理论直接推理参数值，替代纯数学优化方法。Walk-Forward 防过拟合的理念可在后续实现中复用。

## Context
现有参数优化采用网格暴力参数法（grid search）：

- 参数空间被预先离散为有限组合（当前约 ~2160 种）
- 每种组合执行一次完整回测，按指标排序选优
- 全部组合穷举，无任何剪枝

随着系统演进，网格搜索逐渐暴露多重瓶颈：

1. **维度灾难**：ADR-0018 多周期共振引入后，参数维度大幅增加，笛卡尔积导致计算量指数爆炸
2. **样本外失效**：网格搜索仅按全样本指标选最优，未做训练/测试分割，存在严重的过拟合风险
3. **市场结构变化**：曾经最优的参数可能因市场结构变化而失效，需要周期性重优化
4. **缺乏重用**：每次优化都从零开始，未利用历史最优结果

## Decision

> 原方案为 Optuna TPE + Walk-Forward + AdaptiveOptimizer。已被 ADR-0020（网格智能蔡森参数法）取代。

当前三条优化路径：

| 方案 | 命名 | 状态 |
|------|------|------|
| 网格暴力参数法（Grid Search） | 蔡森策略 + 网格暴力参数法 | 已实现 |
| 网格智能蔡森参数法（LLM 驱动） | 蔡森策略 + 网格智能蔡森参数法 | 规划中（ADR-0020） |
| 智能蔡森策略（LLM 直接分析） | 智能蔡森策略 + Prompt Evolution | 已实现 |
