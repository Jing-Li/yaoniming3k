# 对比模式与代码/LLM 双实现

> **状态更新 (2026-05-18)**:
> 已延期。当前优先级是完善核心回测功能和可视化。
> Compare Mode 计划在后续版本实现。

策略支持代码模式和 LLM 模式两种实现，可通过 `compare` 命令对比两者的交易决策和绩效指标。

**为什么**：用户希望验证同一交易逻辑在代码实现和大模型实现下的表现差异，评估 LLM 的决策质量。

**实现**（待实现）：
- 策略描述统一（Prompt 或策略名），实现分离
- `modes` 配置指定运行模式：`[code]`、`[llm]` 或 `[code, llm]`
- 同时运行时生成两个 Result 并输出对比

**对比维度**：
- 绩效指标表格
- 交易差异分析（买入/卖出时机差异）
- 净值曲线叠加图

**替代方案考虑**：
- 策略内双实现 — 同一类包含 code 和 llm 两个方法，增加耦合
- 自动选择 — 根据配置自动选择模式，不支持对比

**后果**：需要两份数据存储（code 和 llm 的结果）；对比命令会增加回测时间。
