# LLM 策略后续任务

## 1. CLI 集成
- **类型**: AFK
- **阻塞**: 无
- **描述**: `caisen run --strategy llm` 支持 LLM 策略运行，从 config 读取 llm 配置
- **验收**:
  - [x] 命令行支持 `--type llm`
  - [x] 自动创建 LLMStrategy
  - [x] 进度显示 LLM 分析状态
- **完成时间**: 2026-05-20

## 2. 缓存持久化
- **类型**: AFK
- **阻塞**: 无
- **描述**: LLM 结果缓存到文件，避免重复调用同名回测
- **验收**:
  - [x] 缓存目录配置
  - [x] 缓存命中跳过 LLM 调用
  - [x] 缓存过期机制（可选）

- **类型**: HITL

- **验收**:
  - [x] PromptEvolver 实现
  - [x] quick_evolution() 接口
  - [x] 评分和规则改进逻辑
- **完成时间**: 2026-05-20

## 4. 标注可视化
- **类型**: AFK
- **阻塞**: 无
