# LLM 策略后续任务

## 1. CLI 集成
- **类型**: AFK
- **阻塞**: 无
- **描述**: `caisen run --strategy llm` 支持 LLM 策略运行，从 config 读取 llm 配置
- **验收**:
  - [ ] 命令行支持 `--type llm`
  - [ ] 自动创建 LLMStrategy
  - [ ] 进度显示 LLM 分析状态

## 2. 缓存持久化
- **类型**: AFK
- **阻塞**: 无
- **描述**: LLM 结果缓存到文件，避免重复调用同名回测
- **验收**:
  - [ ] 缓存目录配置
  - [ ] 缓存命中跳过 LLM 调用
  - [ ] 缓存过期机制（可选）

## 3. Prompt 优化
- **类型**: HITL
- **阻塞**: 无
- **描述**: 规则框架和 Few-shot 示例调优，提升 LLM 信号质量
- **验收**:
  - [ ] 提供默认示例库
  - [ ] 支持 YAML 配置规则
  - [ ] 人工评估信号准确率

## 4. 标注可视化
- **类型**: AFK
- **阻塞**: 无
- **描述**: LLM 生成的标注在回测报告中展示
- **验收**:
  - [ ] buy_signal/sell_signal 渲染
  - [ ] pattern_mark 渲染
  - [ ] 支持自定义标注类型

## 5. 对比模式
- **类型**: AFK
- **阻塞**: 1
- **描述**: LLM vs 代码策略同数据对比，生成对比报告
- **验收**:
  - [ ] 配置多个策略同时运行
  - [ ] 对比指标可视化
  - [ ] 差异信号高亮

## 6. 多 Provider 支持
- **类型**: AFK
- **阻塞**: 无
- **描述**: 支持 Anthropic Claude、本地 vLLM 等
- **验收**:
  - [ ] AnthropicProvider 实现
  - [ ] 配置切换 provider
  - [ ] Provider 错误统一处理
