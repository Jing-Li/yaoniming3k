## Customization Notes

When generating OPS.md, adapt sections based on language:

| Language | Build (§3) | Hot Reload (§8.1) | Test (§8.2) |
|----------|-----------|-------------------|-------------|
| Go | `go build` | `air` or `CompileDaemon` | `go test ./...` |
| Java | `./gradlew build` | Spring Boot DevTools | `./gradlew test` |
| Python | `pip install -e .` | `watchdog` + `python -m` | `pytest` |
| TypeScript | `npm run build` | `ts-node-dev` | `npm test` |
