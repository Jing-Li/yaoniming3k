# Design Tokens Specification — dx/design-system.md Canonical Structure

This file defines the mandatory structure for `dx/design-system.md`. All dx skills that generate or consume the design system MUST follow this format.

## Validation Rules (for dx-review)

When dx-review checks conformance against this file:

1. **Palette**: All color values in code must map to a token defined here. Raw hex not in this table = P1 DRIFT.
2. **Typography**: Font families in code must match the 3 declared roles. Undeclared font = P1 DRIFT.
3. **Spacing**: Spacing values should align with the declared scale. Off-scale values (>2 deviations) = P2 DRIFT.
4. **Anti-Patterns**: If code exhibits any listed anti-pattern = P0 DRIFT.
5. **Signature**: The signature element must be present and functional. Missing = P0 DRIFT.
